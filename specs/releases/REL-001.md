# Release Record: v0.1.0

## Release Overview

Initial foundation release of `mdsearch` delivering local-first collection management,
lexical search (FTS5 BM25), semantic vector embedding (fastembed + sqlite-vector),
and contextual entity graph exploration with in-process GraphQL context queries.
